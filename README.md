# Irregular Verbs

App para estudiar los verbos irregulares de inglés (4º ESO).

Versión actual: v9

https://indalo-apps.github.io/verbos-adela/

## Cómo publicar una versión nueva

1. Sube `APP_VERSION` en `index.html`.
2. Pon el mismo número en `version.json`.
3. Al abrir la app (o volver a ella), el móvil detecta la versión nueva y se recarga solo.

## Créditos de audio

Grabaciones de pronunciación británica de Wikimedia Commons / Lingua Libre (hablantes Back ache, Vealhurl y Pvanp7, y archivos En-uk), con licencias CC BY-SA 4.0, CC BY 3.0 y CC0. Las palabras sin grabación británica usan la voz del dispositivo.
