# Irregular Verbs · 4º ESO

© 2026 **Adela Moreno Vega** y **Carlos Moreno Otto**. Todos los derechos reservados (ver [LICENSE](LICENSE)).

App para estudiar los verbos irregulares de inglés (4º ESO): tarjetas, examen, juegos y pronunciación. Se puede instalar en el móvil y funciona sin conexión.

Se publica con GitHub Pages: https://indalo-apps.github.io/verbos-adela/

## Cómo publicar una versión nueva

1. Sube el número en `<meta name="app-version">` (index.html) y en `CACHE` (sw.js).
2. Añade las novedades de esa versión en `CHANGELOG` (dentro de `index.html`).
3. Pon también el número en `version.json` (solo lo usan las copias anteriores a la v43 para enterarse de que hay versión nueva).
4. Al abrir la app se actualiza sola y enseña las novedades. Si la está usando, sale un aviso con el botón «Actualizar».
